# 숲 탐험

캐릭터 선택창에서 보유 캐릭터를 누르면 확인 버튼 없이 `/game?characterId=…`로 입장한다. 서버의 인증된 캐릭터 목록에서 해당 ID를 찾은 뒤 Phaser를 지연 로드한다. 다른 회원의 캐릭터이거나 삭제된 ID면 선택창으로 돌아간다. 새로고침에도 동일한 확인을 거친다. 캐릭터 생성은 선택창으로 돌아가는 기존 흐름을 유지한다.

## 화면과 에셋

- 지형: 제공된 원본 PNG를 `public/assets/terrain/forest-tiles.png`에 그대로 복사했다. 131×131 시트에는 32×32 타일 16개가 1px 간격으로 배치되어 있다. 프레임 좌표는 `(열 × 33, 행 × 33)`이며 렌더링 시 2배 확대한다. 아이소메트릭 간격은 가로 64px·세로 32px다.
- 나무: 제공된 원본 95×105 PNG를 `public/assets/objects/forest-tree.png`에 그대로 복사했다. 나무 그림을 코드로 생성하지 않으며, 제공 이미지와 타일만으로 잔디·흙길·공터를 구성한다. 나무는 2배(190×210)로 표시하고 밑동 충돌 반경과 그림자도 함께 확대한다. 캐릭터를 가리는 앞쪽 나무만 반투명하게 표시한다. 그림자는 엔진 도형으로 처리한다.
- 맵: `src/game/forestMap.ts`의 고정 시드 64×64 타일 배치다. 중앙 공터에서 시작하고 두 갈래 숲길을 걸을 수 있다. 지도 밖과 나무 밑동은 통과하지 못하며 발 위치의 Y 좌표로 오브젝트 앞뒤 겹침을 정렬한다.
- 나무 밀도: 기존 배치 후보 10개 중 1개만 남겨 기존 수량의 약 10%로 줄인다. 제외된 나무의 그림자와 충돌 영역도 생성하지 않는다.
- 캐릭터: API의 `appearanceCode`에 해당하는 코스튬을 기존 프레임 배치로 표시한다. 이미지가 없으면 기본 시트로 대체한다. 시트는 128×352, 셀은 32×32이며 전용 대기·걷기·점프 프레임으로 8방향을 표시한다. 두 방향키를 함께 누르면 대각선 외형을 사용하고 정수 3배 확대한다. 좌우 반전은 사용하지 않는다.
- 무기: API의 `weapon` 정보로 실제 장착한 외형을 표시한다. 미장착이면 무기를 그리지 않는다. 대기 중에는 캐릭터 오른쪽에서 회전 없이 수직으로만 부유하고, 동작 줄이기 설정으로 입장하면 부유를 정지한다. Z를 누르면 현재 바라보는 방향으로 300ms 동안 휘두르고 원래 위치로 복귀한다. 공격 간격은 최소 400ms이며 북쪽·북서·북동 공격은 캐릭터 뒤에 표시한다. 대각선 공격도 해당 방향으로 휘두른다.
- 닉네임: 머리 위 이름은 픽셀 캔버스 텍스트 대신 14px 굵은 HTML 텍스트로 표시한다. 카메라 렌더링 이후 위치를 맞추며 점프에도 따라간다.
- HUD: 닉네임·현재 레벨(미제공 시 1)·장착 무기·지역 이름을 표시한다. 임의 체력·재화·전투 수치를 만들지 않는다.

전체 분위기는 [세피리아 공식 소개](https://store.steampowered.com/app/2436940/Sephiria/)의 픽셀 탐험 화면을 참고하되, 타 게임의 이미지나 UI 에셋을 복사하지 않았다.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 | 상하좌우 및 대각선 8방향 이동, 대각선 속도 정규화. 속도는 135 → 210px/초로 조정 |
| Space | 제자리 또는 이동 중 점프. 최대 높이 20 → 28px, 지속 480ms. 충돌 영역은 유지 |
| Z | 장착한 무기를 바라보는 방향으로 휘두르기 |
| 캐릭터 선택 | 게임을 종료하고 선택창으로 돌아가기 |

카메라는 지연 보간 없이 플레이어를 즉시 따라가며, 출발·정지 시 배경이 가속·감속하는 느낌을 제거한다. 이동에는 가속을 적용하지 않고 210px/초를 사용한다. 화면 크기 변경과 모바일 화면 회전에 맞춰 리사이즈한다. Tab 기본 포커스 이동 차단은 유지한다. 게임에서 나갈 때 Phaser 인스턴스와 입력 이벤트를 정리하며 브라우저 뒤로·앞으로 가기도 처리한다. 화면이 포커스를 잃으면 이동 입력과 대기 중인 점프·공격 입력을 초기화한다. WASD·클릭·터치 이동과 모바일 이동 패드는 제거했으며 이동은 키보드 방향키만 지원한다.

이 화면은 이동 가능한 초기 맵이다. 몬스터·명중/피해 판정·아이템 획득과 위치 서버 저장은 아직 구현하지 않았다. 재입장하면 중앙 공터에서 다시 시작한다. 게임에 사용하는 캐릭터 외형과 장착 무기는 입장 시 서버에서 다시 조회한다.

프레임 시간 평균 보정을 끄고 실제 경과 시간으로 이동 거리를 계산한다. 40ms를 넘는 프레임도 이동 시간이 잘리지 않도록 하며, 1회 이동을 최대 4px 단위로 나눠 충돌을 검사한다. 브라우저 중단 등 250ms를 초과하는 긴 프레임만 이동량을 제한한다. 로딩이나 렌더링 지연에 의한 순간적인 끊김 자체는 별개지만, 정상적인 저프레임 구간에서 이동 속도가 점점 올라가는 현상은 막는다.

기본 타일·나무·캐릭터 이미지를 읽을 수 없으면 오류 안내와 선택창 복귀 버튼을 표시한다. 선택·로그인 화면에서는 Phaser와 맵 에셋을 미리 로드하지 않는다.

## 인벤토리와 장비창

숲 화면 오른쪽 아래의 `인벤토리`, `장비` 버튼으로 각 창을 열고 닫는다. 두 창을 동시에 열 수 있고 제목줄을 마우스·터치로 드래그하면 위치를 옮긴다. 선택한 창이 앞으로 오며 화면 크기가 바뀌어도 창이 화면 안에 남는다. 닫기 버튼 또는 Escape로 가장 앞의 창을 닫는다. 창을 연 동안 방향키·점프·공격 입력은 중지하고, 모두 닫으면 다시 조작한다. 창을 닫아도 같은 게임에 머무는 동안 위치를 유지한다.

- 인벤토리: 6열의 정사각형 슬롯에 아이템 이미지·수량을 표시한다. 빈칸을 포함해 최소 24칸을 표시하며, 보유 아이템이 더 많으면 행을 추가한다(보유 한도를 새로 제한하지 않는다). 장착한 아이템은 기존처럼 `장착` 배지를 유지한다. 마우스를 올리면 이름·종류·수량·착용 레벨·추가 능력치 툴팁을 표시한다. 클릭·터치로도 정보와 장착·해제 버튼을 확인할 수 있다.
- 장비: 무기·모자를 각각 정사각형 슬롯으로 표시하며 아이템에 마우스를 올리면 같은 툴팁을 제공한다. 인벤토리의 장비를 알맞은 슬롯으로 드래그해 장착한다. 가능한 드롭은 녹색, 종류·레벨·수량이 맞지 않는 드롭은 붉은색으로 표시하고 잘못된 드롭은 요청하지 않는다. 이미 장착한 아이템을 같은 슬롯에 다시 놓아도 해제하지 않는다. 마우스와 터치 포인터를 지원하며 슬롯 밖에 놓거나 Escape를 누르면 드래그를 취소한다. 장착한 슬롯을 클릭한 뒤 `장착 해제`로 해제한다.
- 장비창은 최종 최대 체력·공격력·방어력을 표시한다. 모자는 외형에 표시하지 않으며, 기타·소비 아이템은 보유 확인만 지원한다. 창 드래그는 제목줄에서만 시작한다.
- 창을 열 때와 장착·해제 후 보유 목록 및 캐릭터를 다시 조회한다. 무기 외형·HUD와 능력치는 맵 재입장 없이 갱신하며 캐릭터 위치를 유지한다. 변경 요청은 CSRF 토큰과 보유 아이템 UUID를 사용한다. 중복 요청을 막고 조회 실패 시 재시도를 제공하며, 갱신에 실패한 상태에서는 장비 변경을 막는다.
