# 숲 탐험 — 벨트스크롤

캐릭터 선택창에서 보유 캐릭터를 누르면 확인 버튼 없이 `/game?characterId=…`로 입장한다. 서버의 인증된 캐릭터 목록에서 해당 ID를 찾은 뒤 Phaser를 지연 로드한다. 다른 회원의 캐릭터이거나 삭제된 ID면 선택창으로 돌아간다. 새로고침에도 동일한 확인을 거친다. 캐릭터 생성은 선택창으로 돌아가는 기존 흐름을 유지한다.

## 화면과 에셋

- 지형: 기존 `public/assets/terrain/forest-tiles.png` 원본을 유지한다. 131×131 시트의 32×32 타일 16개를 1px 간격으로 읽고 2배 확대한다. 마름모 타일을 가로 64px, 행 간격 16px의 엇갈린 격자로 배치해 가로로 긴 직사각형 숲길을 만든다. 위아래는 잔디, 이동 구역은 흙길로 표현한다.
- 맵: `src/game/forestMap.ts`에 정의한 같은 3600×900 지형 규격의 숲길 초입과 숲속 공터를 제공한다. 바닥 이동 범위는 X 72~3528, Y 430~690이며 시작점은 (400, 560)이다. 방 양끝과 숲길 위아래 경계를 벗어날 수 없다. 숲길 초입에 `tmffkdla` 몬스터 한 마리를 배치하고, 공터에는 몬스터·NPC를 배치하지 않는다.
- 나무: 기존 95×105 PNG를 그대로 재사용한다. 뒤쪽 숲은 색조·크기를 달리한 세 줄의 나무로 구성하고, 앞쪽 나무와 양끝 나무는 발 위치 Y 좌표로 겹침 순서를 정한다. 캐릭터를 가리는 앞쪽 나무는 반투명하게 표시한다. 신규 이미지나 스프라이트 규격 변경은 없다.
- 캐릭터: API의 `appearanceCode`로 PNG와 `/api/costumes/{code}/sprite` JSON을 읽고 동·서 대기·걷기·선택적 점프·공격·피격·사망을 재생한다. 셀 높이를 화면 기준 96px로 맞춘다. JSON 없는 기존 코스튬은 128×352 시트·32×32 셀·3배 확대를 유지한다. 위아래 이동 중에도 마지막 좌우 방향을 유지한다. 선택창도 같은 JSON의 동쪽 걷기를 사용한다. [에셋 JSON](sprite-assets.md) 참고.
- 무기: API의 실제 장착 무기를 표시하며 미장착이면 숨긴다. 손잡이 기준점을 캐릭터 중심에서 좌우 34px 떨어진 위치에 두어 몸과 간격을 유지하고 바라보는 좌우 방향에 맞춰 든다. 대기 중에는 부유하지 않으며, 걷기·점프 시 손 위치를 따라간다. Z 공격은 손잡이를 축으로 뒤로 당겼다가 전방으로 크게 휘두르고 복귀하는 300ms 동작이며 최소 간격은 400ms다. 맨손 공격과 Z를 누르고 있는 동안의 반복 공격도 지원한다. 점프 중에는 캐릭터와 함께 떠오른다.
- 닉네임: 머리 위 이름은 픽셀 캔버스 텍스트 대신 14px 굵은 HTML 텍스트로 표시한다. 카메라 렌더링 이후 위치를 맞추며 점프에도 따라간다.
- HUD: 닉네임·현재 레벨(미제공 시 1)·장착 무기·지역 이름을 표시한다. 체력·경험치 바와 재화는 서버의 저장된 전투·성장 수치로 표시한다.

기존 에셋을 활용한 벨트스크롤 시제품이다. `mokdo_admin`의 기존 설정을 유지하며 V16부터 게임 백엔드가 전투·아이템 보상·성장을 처리한다. 자세한 내용은 [몬스터 전투와 성장](battle.md)을 참고한다.

## 조작

| 입력 | 동작 |
|---|---|
| ← / → | 좌우 진행 및 바라보는 방향 변경. 이동 속도 210px/초 |
| ↑ / ↓ | 바닥 앞뒤 이동. 이동 속도 126px/초이며 좌우 방향을 유지한다. 대각선 입력은 정규화 후 앞뒤 속도 비율 0.6을 적용한다 |
| Space | 제자리 또는 이동 중 점프. 최대 높이 52px, 지속 480ms. 바닥 좌표와 충돌 영역은 유지하며 그림자는 바닥에 남는다 |
| G | 상호작용. 포탈 100px 이내에서 한 번 누르면 연결된 맵으로 이동 |
| Z | 바라보는 좌우 방향 공격. 누르고 있으면 반복 공격하며 맨손도 지원 |
| 우측 상단 전체화면 아이콘 | 게임과 HUD 전체를 브라우저 전체화면으로 표시. 다시 누르거나 Esc로 종료 |
| 캐릭터 선택 | 게임을 종료하고 선택창으로 돌아가기 |

카메라는 가로로만 플레이어를 즉시 따라가며 방의 양끝에서 멈춘다. 앞뒤 이동과 점프에는 카메라 높이를 유지한다. 화면 높이 ÷ 900으로 줌을 맞춰 작은 화면과 모바일 회전에서도 전체 바닥 깊이를 보여준다. 닉네임 위치에도 줌을 적용한다. 이동에는 가속을 적용하지 않는다. Tab 기본 포커스 이동 차단은 유지한다. 게임에서 나갈 때 Phaser 인스턴스와 입력 이벤트를 정리하며 브라우저 뒤로·앞으로 가기도 처리한다. 화면이 포커스를 잃으면 이동 입력과 대기 중인 점프·공격 입력을 초기화한다. WASD·클릭·터치 이동과 모바일 이동 패드는 제거했으며 이동은 키보드 방향키만 지원한다.

이 화면은 몬스터 생성·추적·피격·사망·리스폰과 캐릭터 체력·사망·부활, 아이템·경험치·재화 지급 및 자동 레벨업을 지원한다. 첫 입장은 숲길 초입의 (400, 560)에서 시작하고 재입장하면 같은 서버 메모리의 전투 위치와 상태를 복원한다. 서버 재시작 시 전투는 초기화하며 캐릭터 체력·아이템·경험치·재화·레벨은 DB에 유지한다. 게임에 사용하는 캐릭터 외형과 장착 무기는 입장 시 서버에서 다시 조회한다.

프레임 시간 평균 보정을 끄고 실제 경과 시간으로 이동 거리를 계산한다. 40ms를 넘는 프레임도 이동 시간이 잘리지 않도록 하며, 1회 이동을 최대 4px 단위로 나눠 충돌을 검사한다. 브라우저 중단 등 250ms를 초과하는 긴 프레임만 이동량을 제한한다. 로딩이나 렌더링 지연에 의한 순간적인 끊김 자체는 별개지만, 정상적인 저프레임 구간에서 이동 속도가 점점 올라가는 현상은 막는다.

기본 타일·나무·캐릭터 이미지를 읽을 수 없으면 오류 안내와 선택창 복귀 버튼을 표시한다. 선택·로그인 화면에서는 Phaser와 맵 에셋을 미리 로드하지 않는다.

## 인벤토리와 장비창

숲 화면 오른쪽 아래의 `인벤토리`, `장비` 버튼으로 각 창을 열고 닫는다. 두 창을 동시에 열 수 있고 제목줄을 마우스·터치로 드래그하면 위치를 옮긴다. 선택한 창이 앞으로 오며 화면 크기가 바뀌어도 창이 화면 안에 남는다. 닫기 버튼 또는 Escape로 가장 앞의 창을 닫는다. 창을 연 동안 방향키·점프·공격 입력은 중지하고, 모두 닫으면 다시 조작한다. 창을 닫아도 같은 게임에 머무는 동안 위치를 유지한다.

- 인벤토리: 6열의 정사각형 슬롯에 아이템 이미지·수량을 표시한다. 빈칸을 포함해 최소 24칸을 표시하며, 보유 아이템이 더 많으면 행을 추가한다(보유 한도를 새로 제한하지 않는다). 장착한 아이템은 기존처럼 `장착` 배지를 유지한다. 마우스를 올리면 이름·종류·수량·착용 레벨·추가 능력치 툴팁을 표시한다. 클릭·터치로도 정보와 장착·해제 버튼을 확인할 수 있다.
- 장비: 무기·모자를 각각 정사각형 슬롯으로 표시하며 아이템에 마우스를 올리면 같은 툴팁을 제공한다. 인벤토리의 장비를 알맞은 슬롯으로 드래그해 장착한다. 가능한 드롭은 녹색, 종류·레벨·수량이 맞지 않는 드롭은 붉은색으로 표시하고 잘못된 드롭은 요청하지 않는다. 이미 장착한 아이템을 같은 슬롯에 다시 놓아도 해제하지 않는다. 마우스와 터치 포인터를 지원하며 창이나 다른 UI 위에 잘못 놓거나 Escape를 누르면 드래그를 취소한다. 가방 아이템을 게임 바닥에 놓으면 이름·전체 수량·복구 불가 안내가 있는 확인창을 표시하고, 확인한 경우에만 해당 칸의 아이템을 모두 삭제한다. 장착 중인 장비는 장착 정보도 함께 삭제한다. 장착한 슬롯을 클릭한 뒤 `장착 해제`로 해제한다.
- 장비창은 최종 최대 체력·공격력·방어력을 표시한다. 모자는 외형에 표시하지 않으며, 소비 아이템은 HP 회복 사용과 퀵슬롯 등록을 지원하고 기타 아이템은 보유 확인만 지원한다. 창 드래그는 제목줄에서만 시작한다.
- 창을 열 때와 장착·해제 후 보유 목록 및 캐릭터를 다시 조회한다. 무기 외형·HUD와 능력치는 맵 재입장 없이 갱신하며 캐릭터 위치를 유지한다. 변경 요청은 CSRF 토큰과 보유 아이템 UUID를 사용한다. 중복 요청을 막고 조회 실패 시 재시도를 제공하며, 갱신에 실패한 상태에서는 장비 변경을 막는다.

전체화면 버튼은 브라우저의 Fullscreen API(지원하는 Safari에서는 WebKit API)를 사용한다. 전체화면 상태에 따라 아이콘·버튼 이름을 변경하며, 캐릭터 선택으로 나가면 전체화면도 종료한다. 미지원 환경에서는 버튼을 비활성화하고 전환 실패는 버튼 아래에 안내한다. 화면 크기 변경은 기존 Phaser RESIZE·카메라 줌으로 반영한다.

## 퀵슬롯과 NPC 상점

화면 하단 중앙에 4칸씩 2줄의 퀵슬롯을 표시한다. 첫 줄은 `Q W E R`, 둘째 줄은 `A S D F`다. 가방의 소비 아이템을 마우스·터치 포인터로 끌어 슬롯에 놓아 등록하고, 슬롯 클릭 또는 해당 단축키로 사용한다. 현재 장비·기타 아이템은 등록할 수 없다. 소비 아이템 중 HP 회복 효과가 없는 아이템도 등록은 가능하지만 사용할 수 있는 효과가 없다고 안내한다.

등록 정보는 `mokdo.quickslots.v1.{characterId}` 키로 이 브라우저의 localStorage에 저장한다. 다른 기기와 동기화하지 않는다. 등록은 보유 행 UUID가 아닌 `{ kind: 'item', itemId }`로 정의를 참조하며, 사용 시 해당 아이템의 현재 보유 행을 찾아 기존 소비 API를 호출한다. 같은 아이템의 여러 보유 행은 수량을 합쳐 표시한다. 소진해도 등록을 유지해 0개로 표시하고 다시 획득·구매하면 사용할 수 있다. 같은 아이템을 여러 슬롯에 등록할 수 있고, 우클릭 또는 슬롯에 포커스를 둔 상태의 Delete/Backspace로 해당 칸만 해제한다. 스킬 등은 이후 별도 kind와 실행 처리를 추가할 수 있도록 슬롯 UI를 분리했다.

키를 누르고 있을 때의 반복 입력, 조합 중 입력, Ctrl/Meta/Alt/Shift 조합과 입력란·편집 영역의 입력은 퀵슬롯을 실행하지 않는다. 요청 중에는 중복 사용을 막고 상점이 열려 있을 때도 사용하지 않는다. 구매·소비·장착 후와 아이템 드롭 보상 수신 시 가방과 퀵슬롯 수량을 갱신한다. 진행 중인 이전 조회가 있으면 완료를 기다린 뒤 변경 후 데이터를 다시 조회한다.

사용 중인 NPC들을 숲길 초입에 배치하고 클릭하면 구매 전용 상점을 연다. 관리자에서 등록한 외형·대화·판매 아이템·가격을 사용한다. 자세한 API와 구매 검증은 [NPC 관리](npcs.md)를 참고한다. 가방·장비창 높이와 이동 범위는 하단 퀵슬롯 영역을 남겨 두므로 작은 화면에서도 드래그 등록할 수 있다.

## G 상호작용과 포탈 이동

숲길 초입의 오른쪽 포탈 `(3400, 560)`에서 G를 누르면 숲속 공터 `(320, 560)`로 이동한다. 공터 왼쪽 포탈 `(200, 560)`에서는 숲길 초입 `(3280, 560)`로 돌아온다. 포탈에 목적지를 표시하고 반경 100px 안에 들어가면 `[G] 이동`을 표시한다. 끝까지 걷는 것만으로는 이동하지 않는다. 기존 숲 에셋을 재사용하며 공터는 바닥 색조를 달리한다.

G 반복 입력·조합·보조키·입력란에서는 실행하지 않는다. 인벤토리·장비·상점·삭제 확인창, 연결 중단, 사망, 숨겨진 탭에서도 이용할 수 없다. 요청 중 추가 이동과 공격을 중지하고 서버가 반환한 맵과 도착 위치를 적용한다. 도착 지점은 포탈 범위 밖이어서 키를 누르고 있어도 왕복하지 않는다.

맵 ID는 전투 응답의 `mapId`이며 `forest` 또는 `clearing`이다. 전투 tick의 선택 필드 `portalId`는 `forest-east` 또는 `clearing-west`다. 서버가 현재 맵·캐릭터 소유·세션·생존·일시 정지 여부·실제 이동 검증 후 위치와 포탈 거리를 확인한다. 잘못된 포탈이나 먼 거리 요청은 이동하지 않는다. 숲 몬스터 상태와 처치 보상은 맵 이동으로 초기화하지 않고 공터에서는 전투하지 않는다. 재접속 시 서버 메모리의 맵·위치를 복원한다. 서버 재시작/30분 유휴 정리 시 초입으로 초기화하며 DB 변경은 없다. NPC 상점은 숲길 초입에서만 표시한다.
